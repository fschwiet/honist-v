Call the Skill tool twice, for "grilling" and "domain-modeling".

During grilling, only update the domain glossary and qualifying ADRs as decisions crystallise. Once the frontier is empty and the user confirms the shared understanding, summarise the settled decisions, then stop and wait for their next instruction. Leave further planning artifacts to an explicit subsequent user instruction, such as `/to-spec` or `/to-tickets`.
